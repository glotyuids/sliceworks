# Lessons from the first run

Three increments, about seventy merged slices, two runtimes. Each lesson names the rule or component it produced.

1. **A session cannot resume what only its conversation knew.** Agent ids and background task ids live in the conversation; after a context compaction the running slices were unreachable. Rule: the session recovery file, updated at every dispatch and merge, read first on resume.
2. **Stalls are invisible without a script.** Implementers hung on a tool or waited on a lock for an hour with no signal. Rule: the stall detector and the stale-process detector, run by the wake timer, printing `STALL` and `STALE` lines the coordinator must act on; the `waiting` state for slices that legitimately pause.
3. **Idle capacity is a cost too.** Ready slices sat while writer slots were free because dependencies were in prose. Rule: `depends_hard`, `depends_soft` and `touches` columns on the slice table; the ready detector; the writer-cap formula; idle capacity hours as a retro metric.
4. **Stale bases are the main rework cost.** Slices built nine to thirteen commits behind the head needed a full rebase round each, and reviews found work that would break on the head. Rule: rebase when the head changed a file the slice also changed; check pinned submodules at merge; never re-pin the T2 worktree during a run; dispatch from the repository root.
5. **Turn limits are hit by waiting, not by working.** Long T1 runs and rebases consumed turns. Rule: count gate wall time separately from work in the budget box; keep T1 under ten minutes by direct-importer scope.
6. **A plan review catches what a code review finds later.** For material-boundary slices, reviewing the implementer's plan against a checklist of recurring defect classes removed whole classes before code existed. Rule: plan review for material-boundary slices (adopted proposal EP-1-3).
7. **A broken hook is silent.** A malformed settings file disabled the rails for hours and cost about a fifth of a window. Rule: a preflight in the wake timer that reports a broken settings file or hook within fifteen minutes (adopted proposal EP-1-1).
8. **Match commands, lose; match diffs, win.** Protected files guarded by matching command text were bypassable and brittle. Rule: protected files enforced at the diff in T0 and T1, with the hook keeping only the hard bans and the main-checkout write targets the diff cannot see (proposal EP-0-2); a red-team corpus that proves the gate turns red.
9. **Named-risk review earns its cost every time.** Every slice touching private data, access or erasure had at least one finding that changed behavior: an erasure that left plaintext behind, an upload that kept streaming after revocation, a service-layer path that skipped the route's check. Rule: the named-risk reviewer is a security invariant and is never pruned.
10. **One parser or none.** Three table parsers, two key-value parsers and three timestamp parsers across the scripts produced two real bugs: a stall detector that crashed on a tuple and a budget hook that could not read an integer reset timestamp written by the second runtime. Rule: one parser library and one schema per file; both runtimes write the same shapes.
11. **Out-of-order merges force renumbering.** Numbered artifacts reserved at dispatch collided when slices merged in a different order. Rule: the coordinator keeps the numbering ledger and reserves at dispatch; renumbering touches names and head pins, so reserve generously.
12. **The owner wants a page, not messages.** Chat progress reports cost tokens and attention. Rule: the dashboard rebuilt every 30 seconds by a script, chat replies of a line or two, notifications for four events only.
13. **A detector that can crash must say so.** The stall detector crashed on a tuple and its stderr was discarded, so for three increments no stall line was ever printed. Rule: a wake timer never discards a detector's stderr; a non-zero exit becomes one `STALL-CHECK-ERROR` line with the last stderr line, and any lines printed before the failure still show. (First-run fix of 2026-10-12, with `test_stall_check.py`.)
14. **Identifiers drift from their regex.** Slice ids gained suffixes (`slice-52b`, `slice-51-phaseA`) that a `slice-\d+$` pattern silently excluded, so suffixed active slices were invisible to the stall check. Rule: one slice-id pattern in the parser library, `slice-\d+[A-Za-z0-9-]*$`, used by every script; the schema documents it. (First-run fix of 2026-10-12.)
